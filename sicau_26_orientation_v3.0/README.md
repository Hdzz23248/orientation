# 四川农业大学信息工程学院迎新互动打卡系统

v3.0 是面向迎新现场大屏的全国新生生源轨迹与数字形象系统，使用 Vite、原生 HTML/CSS/JavaScript、Apache ECharts，以及本地 Node.js + Express 头像代理服务。

## 主要功能

- 按中文、拼音、拼音首字母搜索生源城市。
- 地图视图展示生源地、历史轨迹和雅安校区。
- 关系网视图按“城市 → 省份 → 川农信工”展示层级关系。
- 生成本地 DiceBear Pixel Art 数字形象，支持主题和科技配件。
- 可选百度 AI 头像生成；未配置 AI 时仍可使用本地模式。
- 本地记录支持统计、排行、撤销、导入、导出和清空。
- 支持全屏显示和刷新/切换加载动画。

## 环境要求

- Node.js 22.12+（推荐 Node.js 22 或 24 LTS）
- npm 10+
- Chrome、Edge 或 Firefox 最新版本

## 安装与运行

```bash
npm ci
npm run dev
```

启动地址：

```text
前端：http://127.0.0.1:5173
头像服务：http://127.0.0.1:3001
健康检查：http://127.0.0.1:3001/api/health
```

v3.0 已清理 `node_modules`、`.npm-cache`、`dist` 和环境模板，首次运行需要重新执行 `npm ci`。AI 头像为可选功能；需要时在项目根目录手动创建 `.env`：

```env
BAIDU_API_KEY=控制台中的APIKey
BAIDU_SECRET_KEY=控制台中的SecretKey
AVATAR_SERVER_PORT=3001
```

不要使用 `VITE_` 前缀保存密钥，避免密钥进入前端构建产物。

## 构建与预览

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

`vite preview` 只提供前端静态页面，不会启动 Express，因此不能使用百度 AI 头像接口。

## 使用说明

1. 在左侧搜索并选择生源城市，系统会自动切换到地图视图。
2. 点击“地图 / 树形图”切换可视化方式。
3. 在关系网中悬停省份节点可展开该省城市；悬停中心雅安可查看各省人数。
4. 生成轨迹后，可选择本地数字形象或百度 AI 数字形象。
5. 连续点击顶部版本标识五次可打开本地数据管理面板。

## 数据与隐私

生源记录只保存在当前浏览器的 `localStorage`，键名为 `sicau-welcome-origin-records-v1`。头像和自拍只保存在当前页面内存中，不写入历史记录；页面刷新后会清除头像数据。AI 模式仅在用户明确选择照片并同意后调用本地 `/api/avatar`。
